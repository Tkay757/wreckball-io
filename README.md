# ⛓️ WreckBall.io

A high-performance physics-based wrecking ball arena game built with vanilla HTML5 Canvas and Node.js.

## 🎮 Features
- **Pendulum Chain Physics:** Momentum-based swinging, centrifugal whip forces, and elastic ball-to-ball metallic clashes.
- **Dual-Mode Motorized Controls:** 
  - Mouse / Analog touch to steer
  - `Left Click` (`⟲`) for anticlockwise whip torque
  - `Right Click` (`⟳`) for clockwise whip torque (with snap-reverse braking)
  - `Space` / `Shift` for emergency dodge dash
- **Dynamic Growth:** Collect diamond shards to expand your wrecking ball up to 4.3x size and lengthen your steel chain.
- **Juicy Feedback:** 55ms hit-stop micro-freeze, screen shake, procedural Web Audio SFX (0 external audio files), and streak callouts.
- **6 Flex Skins:** Iron Spiker, Magma Meteor, Cyber Saw, Golden Crown, Plasma Void, Toxic Flail.
- **Smart AI Bots:** 20 roaming bots that orbit at chain distance to whip prey and avoid incoming strikes.

## 🚀 Quick Start
```bash
# Start local server (default port 3001)
node server.js
```
Open [http://localhost:3001](http://localhost:3001) in your browser.
